# 🚦 Road Accident Analysis Dashboard

A data analysis dashboard for road accidents using SQLite, pandas, Streamlit, and Plotly.

## Files
- `app.py` — dashboard UI and charts
- `setup.py` — creates `accidents.db` and `accidents.csv`
- `requirements.txt` — Python dependencies

## Run locally
```bash
pip install -r requirements.txt
python setup.py
streamlit run app.py
```
